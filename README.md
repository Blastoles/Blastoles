## 🎯 Sobre Este Projeto

Este repositório serve como uma **Vitrine Técnica (Showcase)**, projetada para demonstrar na prática a integração de tecnologias complexas de Desenvolvimento de Software e Infraestrutura de TI.

O objetivo não é apenas entregar um software funcional, mas evidenciar o domínio na arquitetura de soluções que unem **Desenvolvimento Web Moderno (UX/UI)**, **Backends Robustos** e **Gestão de Infraestrutura Enterprise**.
